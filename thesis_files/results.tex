\subsection{Security Validation} This section evaluates the security properties implemented by the prototype and demonstrates how cryptographic validation and directory checks protect against common attacks. 

\subsubsection*{Case 1: Action Tampering} Demonstrate: \begin{itemize} \item Create a valid signed action. \item Modify the action contents after signing. \item Verify the modified action. \end{itemize} Expected result: \begin{itemize} \item Signature verification fails. \item The action is rejected. \end{itemize} Discussion: The signature validation mechanism detects modifications to signed actions and protects action integrity. 

\subsubsection*{Case 2: Impersonation Attempt} Demonstrate: \begin{itemize} \item Construct an action claiming Alice's public key. \item Sign the action using a different user's private key. \item Attempt verification. \end{itemize} Expected result: \begin{itemize} \item Signature verification fails. \item The action is rejected. \end{itemize} Discussion: A user cannot successfully publish actions on behalf of another user without possession of the corresponding private key. 

\subsubsection*{Case 3: Repository Replacement} Demonstrate: \begin{itemize} \item Existing directory entry: \begin{itemize} \item Handle: alice.social \item Public key: Key A \end{itemize} \item Replacement repository containing: \begin{itemize} \item Handle: alice.social \item Public key: Key B \end{itemize} \item Execute Follow. \end{itemize} Expected result: \begin{itemize} \item Follow operation fails. \item Profile verification succeeds. \item Directory consistency check fails. \end{itemize} Discussion: This demonstrates identity-continuity protection through comparison of directory and profile public keys. 

\subsubsection*{Case 4: Multi-Hop Replication Trust} Demonstrate: \begin{center} Alice $\rightarrow$ Bob $\rightarrow$ Carol \end{center} \begin{itemize} \item Alice creates a signed action. \item Bob replicates the action. \item Carol receives the action from Bob. \item Carol verifies the action. \end{itemize} Expected result: \begin{itemize} \item Verification uses Alice's public key. \item Bob's repository does not become the trust root. \end{itemize} Discussion: Trust remains anchored to the original author rather than intermediate replication repositories.
